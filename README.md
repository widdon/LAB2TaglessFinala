# Лабораторная работа №2

# «Система управления парковкой на Tagless Final»

## Цель работы

Изучить подход **Tagless Final** в функциональном программировании на языке Scala и реализовать консольное приложение «Парковка» с использованием:

* typeclasses;
* абстракции эффектов `F[_]`;
* interpreter pattern;
* dependency injection;
* разделения слоев приложения.

---

# Постановка задачи

Необходимо разработать систему управления парковкой, поддерживающую:

* въезд машины;
* выезд машины;
* учет времени;
* расчет стоимости парковки;
* штраф за потерянный билет;
* отображение состояния парковки;
* ведение логов.

Программа должна быть реализована с использованием подхода **Tagless Final**.

---

* Scala

* Tagless Final

# Реализация Tagless Final

## Абстракция эффекта

Во всей бизнес-логике используется:

```scala
F[_]
```

вместо конкретного `IO`.

Пример:

```scala
trait Console[F[_]] {

  def printLine(text: String): F[Unit]
}
```

---

# Использование Typeclasses

Для работы с эффектами реализован собственный typeclass Monad.

```scala
trait Monad[F[_]]
```

Это позволяет:

* использовать for-comprehension;
* абстрагироваться от конкретного эффекта;
* заменять runtime без изменения бизнес-логики.

---

# Использование Interpreter Pattern

Алгебры описывают интерфейс:

```scala
Console[F]
```

Interpreter реализует поведение:

```scala
ConsoleInterpreter extends Console[IO]
```

---

# Реализация состояния

Состояние парковки хранится в:

```scala
ParkingState
```

и обновляется immutable способом через:

```scala
copy(...)
```

---

# Реализация меню

Меню реализовано через:

* MenuOption;
* MenuLeaf;
* MenuTreeNode.

Каждый пункт меню представляет собой отдельный объект.

Это позволяет:

* избегать больших match-конструкций;
* расширять меню без изменения существующего кода;
* реализовать polymorphic dispatch.

* возможность замены interpreters;
* высокая тестируемость;
* хорошее разделение ответственности;
* чистая композиция эффектов.
